# Artemis 探索工作区设计原型

本目录保存 Open Design 最终交付的独立交互原型，作为后续桌面端实现的设计参考。

## 查看

使用浏览器打开 [index.html](index.html)，无需安装依赖或构建。也可以通过本地静态文件服务器访问本目录。

交互状态保存在浏览器的本地存储中。设备、执行事件和设备画面均为示例；原型尚未连接真实 HappyCoding、Agent、设备直播或录屏／日志服务。

## 主要流程

- 默认进入探索工作区，通过可收起的侧栏查找、新建和切换 Case。
- 明确选择产品、环境和平台，输入探索目标；首次提交时保存 Case。
- 提交目标后，在左侧消息流卡片中选择设备并开始执行。
- 左侧展示消息、模型输出、决策截图、Action、校验与结果；右侧提供直播、TaskPlan 和事件回放。模拟内容和历史缺失数据均有明确标识。
- 在同一工作区查看历史探索或再次探索；切换 Case 不停止正在执行的本地模拟。
- 账号内部自动获取、HappyCoding 与视频／日志保留均为固定产品约定，不要求用户配置；原型未连接对应服务。

完整设计说明、示例数据边界和待接入能力见 [整合说明.md](整合说明.md)。其中的原项目相对路径是 Open Design 工作区中的来源标识，并非本仓库路径。
